# Paste & Read

Paste any text or article and listen to it instantly.

Paste & Read is a simple web application designed for people who prefer listening over reading. Whether you're reading an article, studying, reviewing notes, or simply want to reduce screen fatigue, Paste & Read converts text into speech with a single click.

https://sierrawild.github.io/paste-and-read/


## Features

- 🎧 Instant text-to-speech
- 📋 Paste any content
- ⚡ No account required
- 🌐 Runs entirely in the browser
- ♿ Helpful for users with dyslexia, ADHD, visual impairments, or reading difficulties
- 📱 Works on desktop and mobile devices

## Keyboard Shortcuts

| Key | Action |
|------|--------|
| Space | Read / Pause / Resume |
| Esc | Stop reading |
| ← Left Arrow | Previous sentence |
| → Right Arrow | Next sentence |

## How It Works

1. Copy text from any source.
2. Paste it into the text box.
3. Press **Read**.
4. Listen while the browser reads the content aloud.

No uploads, no complex settings, and no unnecessary distractions.

## Accessibility

Paste & Read aims to be accessible and easy to use:

- Simple and uncluttered interface
- Quick and fast
- Does what it says it does. No more, no less
- Everything stays on your machine. Data isn't sent to a server
- Keyboard-friendly controls
- Supports browser text-to-speech engines
- Automatic dark mode based on system settings
- Useful for users with dyslexia, ADHD, and other reading challenges

Accessibility improvements and suggestions are always welcome.
